The web has started serving two internets.

One to you, and one to the agent you sent. This is a record of the difference, measured the same way every time, published whether or not the numbers are interesting.

What each site did

How it is measured

One homepage per site, fetched once per identity from the same machine within seconds of itself. Exactly one thing changes between fetches: who the client says it is. Everything else is held still, because everything else is what would otherwise explain the difference.

Nothing is bypassed. No login, no CAPTCHA solving, no proxy rotation, and no pretending to be a browser we are not. When a site refuses a client, the refusal is the measurement.

What this does not show

The control is not a real browser. It is a command line client sending a browser user agent string. It runs no JavaScript and carries no browser TLS fingerprint, so a site that refuses it is refusing non browser clients in general. That is a different claim from refusing agents, so those sites are marked not comparable and dropped from the denominator rather than counted against anyone.

Where you measure from changes the answer. The same 72 sites, measured the same way on the same day from a home connection and from a datacentre, disagreed on 18 of them. Amazon served an agent from one and refused it from the other. So runs are labelled by vantage and never averaged: one number covering both would be true of neither.

This measures the front door, not the price. One homepage, one location, one moment. It says whether an agent is let in and whether it is handed the same page. It does not say what an agent is charged, and no number here should be read that way.
